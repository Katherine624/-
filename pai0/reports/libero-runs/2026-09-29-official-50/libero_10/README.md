# LIBERO-10 正式免训练评测

使用官方发布的 `pi0_libero` 权重，未进行任何训练。10 个任务各运行 50 次，共 500 次；成功 405 次，成功率 **81.0%**。这属于公开 LIBERO 代理实验，不是论文中的私有真实机器人实验。

- `evaluation.log`：原始运行日志，记录每次成功/失败；运行退出码为 0。
- `summary.json`：从日志重新解析并校验的机器可读结果。
- `task_results.csv`：10 个任务逐任务成功率。
- `episode_results.csv`：500 次 rollout 的逐次成败。
- `videos/`：500 段逐次视频，文件名含任务和次数，不会覆盖。
- 上级目录中的 `libero_10.tar.gz` 为云端原始归档，SHA-256 为 `556e96552682acfaa15b009bba0a4615bb731f6497d08d9346352a6ed029b1f0`，本地已与云端校验一致。
